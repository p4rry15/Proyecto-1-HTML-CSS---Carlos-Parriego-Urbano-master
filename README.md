# Portfolio Personal - Carlos Parriego Urbano

¡Bienvenido a mi repositorio! Este proyecto consiste en mi **Portfolio Personal**, desarrollado como parte de mi formación en **ASIR (Administración de Sistemas Informáticos en Red)**.

En este sitio web presento quién soy, mis aficiones y una recopilación de los proyectos técnicos que he realizado durante mis estudios.

## 📋 Descripción

Esta es una página web estática diseñada para servir como carta de presentación profesional. El sitio cuenta con una navegación fluida, un diseño moderno y adaptativo (responsive), y secciones dedicadas a mostrar mis habilidades tanto en hardware y redes como en desarrollo web básico.

### 🚀 Tecnologías Utilizadas

**HTML5**: Estructura semántica del contenido.
**CSS3**: Estilos personalizados, incluyendo:
    * Diseño Responsivo (Media Queries).
    * Uso de Flexbox y Grid Layout.
    * Fuentes personalizadas de Google Fonts (Oswald, Montserrat, Lobster).
    * Variables CSS para una gestión eficiente de colores y estilos.

## 🗂️ Estructura del Sitio Web

El portfolio (index.html) está organizado en las siguientes secciones:

1.  **Inicio**: Portada con navegación visual rápida a las secciones principales.
2.  **Sobre mí**: Una breve biografía donde explico mi pasión por la informática, el networking y mis objetivos profesionales como futuro administrador de sistemas.
3.  **Hobbies**: Una sección visual donde comparto mis aficiones personales (viajar, pesca, etc.).
4.  **Proyectos**: Área destacada donde muestro trabajos realizados en clase:
    * **Redes**: Simulación de VLANs y topología de red para un colegio (Packet Tracer).
    * **Hardware**: Documentación técnica y presupuesto para el montaje de un PC Gaming.
    * **HTML + CSS (Canción)**: Un enlace a una página interna (cancion.html) donde estructuro la información de un tema musical ("Diabla" de Los Diozes) utilizando tablas complejas y multimedia.
5.  **Contacto**: Formulario funcional (visual) para contactar conmigo.

## 📂 Página Adicional: Proyecto Canción

El repositorio incluye un archivo cancion.html, que es un proyecto específico de la asignatura "Lenguaje de Marcas".
**Objetivo**: Maquetar la ficha técnica de una canción.
**Características**: Uso intensivo de tablas HTML (<thead>, <tbody>, colspan), incrustación de audio y video, y estilos específicos.

## 🛠️ Cómo visualizar el proyecto

1.  Clona este repositorio o descárgalo como ZIP.
2.  Abre la carpeta del proyecto.
3.  Haz doble clic en el archivo index.html para abrirlo en tu navegador web favorito.
4.  Desde la sección de "Proyectos", puedes navegar a la página de la canción o descargar los documentos adjuntos.
